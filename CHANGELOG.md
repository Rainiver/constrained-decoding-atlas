# Changelog

All notable changes to the Atlas are recorded here. Releases follow semantic
versioning for the data contract: breaking schema or vocabulary changes increment
the major version; new compatible records or views increment the minor version;
metadata corrections increment the patch version.

## [0.2.0] — 2026-07-31

README-first release:

- moved the complete 49-paper catalog, field snapshot, libraries, and reading
  path into the repository front page;
- distinguished 17 fully coded papers, 9 full-text-screened papers, and 23
  metadata-verified records in every generated view;
- added seven full-text codings covering DCCD, DISC, Formatron,
  automata-based constraints, GreatGramma, format restrictions, and
  reasoning-before-constraining;
- added a project banner and concise discovery links while retaining the
  filterable website as an optional view;
- clarified that catalog counts are coverage diagnostics, not estimates of
  field-wide prevalence.

## [0.1.0] — 2026-07-31

First public preview:

- 49 machine-readable records spanning 2017–2026;
- seven-axis taxonomy and guarantee glossary;
- evidence-status workflow separating discovery from synthesis;
- interactive searchable website and generated Markdown views;
- schema, standard-library validator, and GitHub Actions checks;
- dual licensing: MIT for code and CC BY 4.0 for original annotations/docs;
- contribution forms, citation metadata, and recorded discovery protocol.
