## Milestone 3 — Community resource

- [ ] Publish a searchable static website.
- [ ] Add issue and pull-request templates.
- [ ] Add monthly stale-link and metadata checks.
- [ ] Tag quarterly catalog snapshots and release a DOI-backed archive.
- [ ] Invite maintainers from formal methods, NLP, and inference systems.

## Milestone 4 — Publication decision

Only consider a survey/perspective manuscript after the catalog is stable and
the associated main empirical paper is outside conflicting archival-review
restrictions. The repository remains useful even if no survey is written.
