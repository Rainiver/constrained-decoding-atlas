How to read the Atlas

Four separations prevent most category errors.

01

Validity ≠ quality

A parseable string can still be semantically wrong. We code structural and task outcomes separately.

02

Soundness ≠ coverage

Emitting only grammatical strings does not prove that every intended string remains token-reachable.

03

Local mask ≠ conditional sample

Stepwise renormalization is not automatically the base sequence distribution conditioned on validity.

04

Proposal validity ≠ safe commit

Structured output and runtime authorization operate on different properties and lifecycle boundaries.
