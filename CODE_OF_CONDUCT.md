# Community Code of Conduct

The Atlas is a technical evidence resource. Participation requires respectful,
specific, and source-grounded collaboration.

## Expected behavior

- Critique classifications and claims, not people.
- Link primary evidence and state uncertainty plainly.
- Welcome corrections, including corrections that weaken a favored conclusion.
- Respect attribution, licensing, privacy, and research-integrity obligations.
- Keep discussion relevant to maintaining a useful scholarly resource.

## Unacceptable behavior

Harassment, discriminatory language, threats, deliberate misinformation,
plagiarism, doxxing, and sustained off-topic disruption are not tolerated.

## Enforcement

Report conduct concerns privately to the repository owner through the contact
address on their GitHub profile. Maintainers may edit or remove content, close
threads, or temporarily or permanently restrict participation. Enforcement
decisions should be proportionate and documented when privacy permits.

This policy applies in repository issues, pull requests, discussions, and other
project-managed spaces.
